# 🐹 Squeekchain Genesis Console & Live Suite

A 16-bit retro arcade dashboard and live oracle ecosystem built for **Squeekchain** — featuring Proof-of-Distance (PoD) hamster wheel telemetry, prediction markets, dynamic evolving vector NFTs, stream companion overlays, and non-custodial SQK staking vaults.

![Squeekchain Banner](https://placehold.co/1200x630/0d1322/f59e0b?text=SQUEEKCHAIN+GENESIS+CONSOLE)

---

## 🌟 Features

- **⚡ Proof-of-Distance (PoD) Live Oracle**: Real-time IoT wheel telemetry simulation converting physical hamster run distance into block height confirmations and difficulty adjustments.
- **📈 SqueekFi Prediction Market**: Stake SQK tokens to wager on whether the hamster's next block run distance will be LOW (<50m) or HIGH (≥50m) with live payout ledgers.
- **🧬 Dynamic Trait-Evolving NFTs**: SVG Squeek NFTs whose traits (Headbands, Golden Crowns, Cosmic Laser Eyes, Auras) dynamically mutate as lifetime distance milestones are unlocked.
- **🎥 Stream Companion Overlay**: Zero-latency, browser-ready OBS overlays displaying active block runs, predictions, and community pool pots for Twitch/YouTube creators.
- **🧰 Non-Custodial Holder Vault**: Stake SQK tokens for block execution yield rewards and synthesize new NFT trait layers in the Fusion Matrix.
