What does it do, and how does it use Squeekchain?
Squeekchain Genesis Console is an all-in-one interactive web app powered by Squeekchain's Proof-of-Distance (PoD) oracle architecture. Key Features & Squeekchain Integrations: 1. Proof-of-Distance Wheel Engine: Real-time telemetry simulation of hamster wheel IoT runs powering block confirmation and dynamic difficulty adjustments. 2. SqueekFi Prediction Markets: Non-custodial prediction betting on block distance outputs (HIGH/LOW runs) with 2x SQK token rewards. 3. Dynamic Evolving NFTs: SVG Squeek NFTs whose visual traits (Bandanas, Golden Crowns, Laser Eyes) automatically mutate as cumulative hamster distance milestones are reached. 4. AI Oracle & Narrative Stream: Real-time AI narrative generator logging live story updates per mined block. 5. Stream Companions: OBS browser overlay widgets displaying live block data and prediction pools for livestreamers. 6. Holder Vault: Non-custodial SQK staking and trait synthesis chamber for NFT holders.
